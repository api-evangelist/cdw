## APIs

### CDW Catalog API

The CDW Catalog API uses JSON to deliver customers real-time pricing and inventory status alongside any special pricing or catalog restrictions. It supports integration with eProcurement platforms for current product availability.

**Human URL:** [https://www.cdw.com/content/cdw/en/services/eprocurement-and-custom-catalogs.html](https://www.cdw.com/content/cdw/en/services/eprocurement-and-custom-catalogs.html)

### CDW eProcurement Integration

CDW eProcurement integration supports PunchOut and Roundtrip catalogs via cXML or OCI, electronic purchase order submission via cXML, EDI, or flat file, and electronic invoicing via XML or EDI. Orders can be submitted via HTTP, SFTP, API, and EDI connections.

**Human URL:** [https://www.cdw.com/content/cdw/en/services/eprocurement-and-custom-catalogs.html](https://www.cdw.com/content/cdw/en/services/eprocurement-and-custom-catalogs.html)
